below and in `work/neb_observed.json`. Kept as the procedure for re-running it.

**The condition must be `BsaI-HFv2 37-16 cycling`.** Pryor Table S1 is the

This is the one validation step that cannot be automated here. The NEB viewer is a web tool;
CLIPPR must not submit anything to it automatically, and screen-scraping a vendor tool would
be both fragile and rude. So it needs you.

---

## Why it matters

CLIPPR predicts ligation fidelity from the **Pryor et al. 2020** mismatch data, which is the
same published dataset NEB's viewer is built on. If two independent implementations of the
same published data disagree, one of them is wrong — and it could be ours.

Everything else in this project has been checked against something. This number has only ever
been checked against itself.

---

## What to do

Go to **<https://ligasefidelity.neb.com/>** (NEBridge Ligase Fidelity Viewer).

Set the conditions to match what CLIPPR assumes:

| Setting | Value |
|---|---|
| Overhang length | **4-base** |
| Ligation conditions | **BsaI-HFv2 37-16 cycling** |

The overhangs box takes a **comma-separated** list. Clear NEB's default example first.

Then enter each of the four overhang sets below, one at a time, and record the fidelity the
viewer reports.

### The four sets

These are every distinct Golden Gate reaction across the 9S, 14S and 19S architectures. Each
set already includes the destination's two ends.

**Set 1** — appears in 9S reaction 0, 14S reaction 0, 19S reaction 0

```
CTCA,ACTC,AAGA,GCAC,TGAA,CTTC,CTCG
```

**Set 2** — appears in 9S reaction 1, 14S reaction 2, 19S reaction 3

```
CTCA,ACTC,AAGA,GCAC,TGAA,CTCG
```

**Set 3** — appears in 14S reaction 1, 19S reaction 1

```
CTCA,ACTC,AAGA,GCAC,TGAA,GTGA,CTCG
```

**Set 4** — appears in 19S reaction 2

```
CTCA,ACTC,AAGA,GCAC,TGAA,CACG,CTCG
```

### One detail that matters

The last overhang in each set is **`CTCG`, not `CGAG`**.

The deposited vector records its 3′ end as the coding site `CGAG`, but the strand that
physically anneals in the tube is its reverse complement, `CTCG`. `CTCA` and `CTCG` differ by
a single base, which is exactly the kind of near-match that costs fidelity — so entering
`CGAG` would describe a reaction that does not happen.

## How to read the result

**Close agreement** (within a percent or two) is the outcome that costs nothing and settles
the question: two independent implementations of the same published data agree, and CLIPPR's
fidelity numbers can be quoted with that behind them.

**A consistent offset** across all four sets points at an aggregation difference, not an
error. CLIPPR pools a set with its Watson–Crick pairs and takes the geometric mean of
directional products; NEB may normalise differently. That would be worth documenting, not
fixing.

**Disagreement that varies set to set** is the one that matters. It would mean one
implementation is reading the matrix differently, and CLIPPR's is the one we can inspect.
Send the numbers and I will work out which.

**Either way, nothing here is a measurement.** Both tools predict from the same 2020 dataset.
Agreement between two predictions is not experimental validation of either.

## Reference values, for the record

Generated by `work/neb_panel.json`:

- matrix: **BsaI-HFv2**, fingerprint `f5e4da3cacff1577`
- scorer version: **2** (the version after the denominator fix — the earlier one summed only
  reverse complements and gave a set/rc asymmetry of 0.43 where the corrected form gives
  2.2×10⁻¹⁶)
- aggregation: geometric mean of directional products, with the set pooled against its
  Watson–Crick pairs

To regenerate the panel:

```bash
python -c "import sys; sys.path.insert(0,'src'); import json; from clippr import inventories as inv; from clippr.overhangs import reaction_overhangs, set_fidelity; lib=inv.load_deposited(r'data/grasp_supp/Table S1.xlsx'); print(json.dumps({t: [reaction_overhangs([j['overhang'] for j in inv.compile_target(lib,t)['junctions'] if j['reaction']==r],'level0') for r in range(inv.compile_target(lib,t)['reactions'])] for t in ('AAAAUGUGG','UUACACGUGCGUAC','CUAUCACAUCACAUAAGCG')}, indent=2))"
```
