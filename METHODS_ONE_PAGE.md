# PPROPT — methods and parameters

*13 October 2026. Two Colab notebooks, no local install.* **Designer:** give it an RNA target,
get a brand-new gene cut into synthesis fragments. **Inventory:** you hold the 42-part GRASP
kit; it recodes those modules for your host and compiles targets from them.

## Methodology

1. **Read the target** — length picks the architecture: 9 / 14 / 19 nt → 9S / 14S / 19S.
2. **Pick the repeats** — the PPR code is mechanical: `A→TN, C→NN, G→TD, U→ND`.
3. **Write the protein** — repeats plus the published scaffold ends.
4. **Choose cut positions *before* the codons.** Optimising first would let the optimiser
   rewrite the bases the junctions depend on.
5. **Protein → DNA**, picking codons the host reads easily, under the rules below.
6. **Check what would actually be ordered** — the gene *plus* the entry overhang and enzyme
   wrapper bolted on each end.
7. **Decide** — an order sheet, or a refusal naming the rule that broke. A refusal still
   writes the files, labelled `REJECTED`.

**Rules enforced** (profile `ppropt-strict-legacy`, all hard): local GC **0.35–0.65** over
every 50-nt sliding window · homopolymer **≤ 4** · forbidden sites **BsaI, BbsI, SapI**.

**The decision that made the de novo route work.** The GC band was checked on the coding span,
but the *ordered fragment* carries GC-rich joining bases the optimiser never saw. The gene sat
at 0.640 and the ordered piece reached 0.660 — one base over — and all 200 saved designs
failed that way. We did not widen the band; we showed the optimiser the whole ordered fragment
(`wrapper_aware=True`, default since 12 Oct). **200 of 200 orderable, 1050 fragments, 0 hard
findings**, typical codon cost 0.003. The control is what makes it attributable:
`wrapper_aware=False` reproduces the old sequences exactly, base for base, across all 200.

## Parameters

**Designer** — `target_rna` `AAAAUGUGG` · `organism` · `assembly_enzyme` `BsaI` ·
`ligation_table` `BsaI-HFv2` · `enzyme_profile` `igem_rfc1000` · `destination_level` `level0` ·
`seed` `42` · `n_fragments` `0` (auto) · `check_offtarget` `True` · `write_files` `True`.
Optional: `codon_table_file`, `kazusa_taxid`, `genetic_code_override`, `extra_blacklist`,
`custom_destination`.

**Inventory** — `organism` · `table_s1` `Table S1.xlsx` · `label` `my-host` ·
`candidate_seeds` `4` (1–8) · `recode_seconds` `600` · `inventory_targets` · `fusion_site`
`AATG` · `mode` `greedy` (greedy/anneal/random) · `max_proposals` `168` · `max_evaluations`
`100` · `choice` `recommended` (or incumbent).

**Six hosts:** `c_reinhardtii_nuclear`, `c_reinhardtii_chloroplast`, `e_coli`, `s_cerevisiae`,
`a_thaliana_nuclear`, `n_tabacum_chloroplast`. The two chloroplast tables use genetic code 11,
the rest code 1. Changing `organism` changes the recoded DNA and so the inventory version,
which is a content hash of the sequences.

## How we made them ready

- **1229 automated tests** on every change; a second, independently written checker re-derives
  the 200-design corpus and agrees on all 200.
- **Both notebooks execute end to end** in the release gate, not just parse. The inventory
  route once shipped having never run — three cells raised the moment a real input reached
  them while every static test stayed green.
- **Every host exercised:** all six driven through the full inventory notebook, 12 cells and
  0 failures each, each producing 42 assembly-ready substrates in 1 pool, every one inside the
  synthesis contract, with a distinct inventory version.
- **Refusals explain themselves.** A task that refuses without writing anything stops the
  chain and prints why; a task reporting a *partial* result still hands you the other 41
  modules.

## What we do not claim

**Nothing biological is measured** — no binding, no expression; every number is a prediction
or a software check. **No vendor has accepted or refused anything**, so passing our policy is
not vendor acceptance. **The GC band is our own engineering choice**, settled 13 Oct: equal to
Twist's codon-optimisation guidance numerically, enforced harder than that document frames it,
and absent from every IDT document — and IDT is who we order from. **The 200 designs are
synthetic**, generated by this software and frozen so every check measures the same set.
